## Item 4 — pipeline timing (no I/O)

53 processors, **6.7 ms** wall, **0 I/O** (all data pre-fetched into params). Top: SystemDate 1.60 / MessageContent 0.61 / HistoryTruncate 0.48 / TopicReference 0.43 / PlaceholderVariables 0.38. The rest ≤0.25 ms.

Dependencies (do **not** parallelize blindly):

- Phase 1 `HistoryTruncate` must run first.
- Phase 2 appends to **one** system message (`SystemRoleInjector` creates it).
- Phase 3 writes a **shared** first-user injection; order is user-visible.
- Phase 4 almost all target the **last user** message.
- Phase 5 flatten **before** `PlaceholderVariables`.

Contiguous no-dep segment = the ~30 disabled injectors that only check `enabled` and return. Parallelising those: ~1.2 ms serial → ~0.3 ms (4-way) ≈ **−1 ms**. Not worth a `pipeline.ts` edit this batch.
