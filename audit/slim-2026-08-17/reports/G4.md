## Round 3 (commander regressions)

Fixed cache semantics (not the commander tests):

1. **Rejected AI publish leaked into `getPublished()`** — slot was keyed only by generation/epoch, so a previous test's published catalog (or an in-tx view) survived `TRUNCATE` of providers. Slot is now also keyed by cheap pointer identity; open transactions never populate the slot; failed loads drop it; no placeholder snapshot. Checksum memo includes the stored checksum so reused `providerId:revision` with a different payload rehashes.
2. **Connector-governance publish invisible in-process** — the ≤1s `getPlatformConfigScopeVersion` memo hid a bump from `InMemory.publish` / `getPlatformConfigInvalidationPublisher()`. Memo is now single in-flight dedupe only; `publish` still drops the slot immediately.
3. **Rolled-back AI pointer not visible to `applyImmediate`** — `assertPublishedPlatformAiReferences` loads the snapshot inside a `Transaction`. That path is always live now, so a pointer moved to an older revision is seen immediately (not the newer cached slot).

Mocks: `skillCatalog/publication.test.ts` already exports `onAiCatalogAuthorityInvalidate`. Other `catalogTokens` / `platformConfigInvalidation` mocks did not need new exports.
