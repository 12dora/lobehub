     scope-correction: The finding is factually correct about the code but overstates severity. Reachability requires an ops-level env-flag toggle (process.env, needs restart), not a routine or attacker-triggered action. It affects the user's own credential retention, not an auth bypass or cross-user leak. Also the cited line is 70, not 66 (the quoted code is exact; minor drift).
