# Partition: i18n

## Summary

The 2,280-key admin locale sets are structurally aligned, with no missing zh-CN keys relative to en-US and no clearly untranslated prose among the 21 identical values. However, nine keys used by the admin console are absent from all locale sources, causing English fallbacks in zh-CN. CRITICAL: 0 · HIGH: 0 · MEDIUM: 1 · LOW: 1.

## Findings

### F1 \[MEDIUM]\[D4] Identity-provider disable and restart-failure flows fall back to English

- **Location:** `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:85`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:88`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:93`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:94`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:102`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:115`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:120`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:124`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:263`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:290`, `src/enterprise/client/features/admin/identityProviders/IdentityProviderPage.tsx:308`, `packages/locales/src/default/admin.ts:1812`, `packages/locales/src/default/admin.ts:1882`, `locales/en-US/admin.json:1180`, `locales/en-US/admin.json:1239`, `locales/zh-CN/admin.json:1180`, `locales/zh-CN/admin.json:1239`
- **Evidence:** The page calls keys such as `t('identityProviders.disable.cancel', { defaultValue: 'Cancel' })`, `t('identityProviders.disable.impact', { defaultValue: 'This publishes a signed tombstone revision…' })`, and `t('identityProviders.restart.failedWithCategory', { defaultValue: \`Restart failed (...)\` })`. Eight unique referenced keys are absent from all three locale files: `identityProviders.disable.cancel`, `identityProviders.disable.impact`, `identityProviders.disable.confirm`, `identityProviders.disable.title`, `identityProviders.disable.success`, `identityProviders.restart.failedWithCategory`, `identityProviders.columns.actions`, and `identityProviders.actions.disable\`.
- **Impact / failure scenario:** A zh-CN administrator disabling an identity provider sees the action, irreversible-impact warning, confirmation, and success feedback in English. A categorized restart failure also appears in English. This affects a destructive authentication change whose consequences should be unambiguous.
- **Fix:** Add all eight keys to `admin.ts` and mirror them in en-US and zh-CN, supplying complete Simplified-Chinese translations, including the signed-tombstone and login-termination warning.
- **Confidence:** HIGH

### F2 \[LOW]\[D4] Pending provider connection-test message lacks a locale entry

- **Location:** `src/enterprise/client/features/admin/ai/providers/ProviderConnectionTestPanel.tsx:44`, `packages/locales/src/default/admin.ts:328`, `locales/en-US/admin.json:275`, `locales/zh-CN/admin.json:275`
- **Evidence:** The pending branch renders `t('aiCatalog.editor.test.message.pending', { defaultValue: 'Connection test in progress' })`. The locale family defines `aiCatalog.editor.test.message.failure` and `.success`, but `.pending` is absent from all three files.
- **Impact / failure scenario:** While a connection test is pending, zh-CN displays the English fallback inside the localized test summary.
- **Fix:** Add `aiCatalog.editor.test.message.pending` to all three locale sources with an appropriate zh-CN translation such as `连接测试正在进行中`.
- **Confidence:** HIGH
