# 运行时品牌视觉回归契约

此契约覆盖 Published 品牌快照从管理后台到公开认证页、主界面和关闭功能开关后的回退行为。执行时使用隔离数据库，并保留浏览器截图与 DOM 证据；不要把测试品牌写入共享开发库。

## 固定测试品牌

| 字段                      | 值                               |
| ------------------------- | -------------------------------- |
| 平台名称                  | `Aster Works`                    |
| 短名称                    | `Aster`                          |
| 法定名称                  | `Aster Works Pte. Ltd.`          |
| 默认 Agent                | `Aster Copilot`                  |
| 页面标题模板              | `%s · Aster Works`               |
| 主页 / 支持 / 条款 / 隐私 | `https://example.com` 下对应路径 |

运行时资源字段允许为空；为空时 Logo 与 favicon 必须使用内置资源，不能声称验证了自定义资源上传。

## 验证矩阵

1. 在 `ENABLE_PLATFORM_ADMIN=1`、`ENABLE_RUNTIME_BRANDING=1` 下保存草稿。管理页必须显示待发布状态，实时预览显示草稿名称，公开页面仍保持上一个 Published 版本。
2. 发布同一草稿。管理页标题、状态、版本号和预览必须切换到新 Published 版本；公开页面随后读取同一 revision。
3. 未登录访问认证页：
   - 宽屏中文和 `390 × 844` 移动视口均显示 `Aster Works`；
   - 英文至少覆盖一个视口；
   - 表单协议与页脚的主页、支持、条款、隐私链接全部来自 Published 快照。
4. 已登录访问主界面：页面标题使用 Published 标题模板；导航与页面内容不得重新引入已清理的平台硬编码。
5. 对发布前后分别记录标题、主标题、状态或 revision 的 DOM 证据，以验证生效时序，不用一张发布后截图代替时序验证。
6. 保留自定义资源为空时的 favicon DOM URL，确认它明确回退到内置 favicon。
7. 使用同一数据库，以 `ENABLE_RUNTIME_BRANDING=0` 重启服务。认证页名称、公开链接、主界面标题和 favicon 必须全部恢复为内置默认值，即使数据库仍有 Published 自定义版本。

## 通过标准

- 每张证据截图都需要人工目检，无截断、重叠、溢出或未完成加载状态。
- 中文和英文均不得显示未解析的 `{{platformName}}` 插值。
- 报告必须区分 “自定义资源已验证” 和 “空资源回退已验证”；本地对象存储不可用时只允许记录后者。
- 完成后关闭浏览器会话、开发服务与本次创建的隔离容器，并确认源代码不存在测试专用注入标记。
