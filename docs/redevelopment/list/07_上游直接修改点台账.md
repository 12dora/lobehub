## 规则

1. 任何新增上游直接修改必须更新本表，说明替代方案为何不可行。
2. 优先新增方法、Adapter 和注册器，不改旧公共签名。
3. 每次上游 Rebase 生成冲突报告和行为回归报告。
4. 对高风险文件建立 focused tests，尤其 RBAC Middleware、User Settings、Better Auth 和 Router Root。
