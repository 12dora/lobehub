| /admin/skills             | Skill         | platform\_skill:read          | 版本 / 校验               |

## 路由实现要求

- 通过 `BusinessDesktopRoutesWithoutMainLayout` 注册；Web/Electron 同步。
- 匿名用户跳登录；已登录无权限显示 403；不加载敏感数据。
- 菜单权限只影响可见性，Procedure 权限才是安全边界。
- 移动端首版显示明确不支持页面，不渲染桌面表格缩小版。
- 页面均需覆盖 loading、empty、error、forbidden、revision conflict、read-only、pending restart。

## W2 实施状态

- `/admin`、`/admin/users`、`/admin/users/:id` 已在 M03/M04 落地；desktop/web route tree 同步，企业 Flag 关闭时 registry 返回空数组。
- 移动端 `/admin` 已落地明确不支持面，不加载桌面管理表格。
- 用户详情已包含 Overview、Access、Sessions、Audit、Danger Zone；Audit 无权限时不发请求。
- 其余 URL 保留为后续模块交付，不得用占位管理写接口提前驱动运行时。
