# 前端路由与页面清单

| URL | 页面 | 最低权限 | 主要内容 |
| --- | --- | --- | --- |
| /admin | Overview | platform_admin:access | 系统状态摘要、待处理发布 |
| /admin/users | 用户列表 | platform_user:read | 搜索、筛选、分页 |
| /admin/users/:id | 用户详情 | platform_user:read | Access/Sessions/Audit |
| /admin/settings | 设置策略 | platform_settings:read | 默认/锁定/隐藏 |
| /admin/ai/providers | Provider | platform_ai_provider:read | 列表/状态/测试 |
| /admin/ai/providers/:id | Provider 编辑 | platform_ai_provider:update | Draft/Published 对比 |
| /admin/ai/models | Model | platform_ai_model:read | 模型列表/依赖 |
| /admin/skills | Skill | platform_skill:read | 版本/校验 |
| /admin/connectors | Connector | platform_connector:read | 定义/Tool/凭据模式 |
| /admin/agents | 平台 Agent | platform_agent:read | 版本/Assignment/Rollout |
| /admin/identity/providers | OIDC Provider | platform_identity:read | 向导/激活状态 |
| /admin/branding | Branding | platform_branding:read | 实时预览 |
| /admin/audit | Audit | platform_audit:read | 过滤/详情/受限导出 |
| /admin/system | System | platform_system:read | 依赖、Revision、Job、实例 |

## 路由实现要求

- 通过 `BusinessDesktopRoutesWithoutMainLayout` 注册；Web/Electron 同步。
- 匿名用户跳登录；已登录无权限显示 403；不加载敏感数据。
- 菜单权限只影响可见性，Procedure 权限才是安全边界。
- 移动端首版显示明确不支持页面，不渲染桌面表格缩小版。
- 页面均需覆盖 loading、empty、error、forbidden、revision conflict、read-only、pending restart。
