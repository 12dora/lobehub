## 路由实现要求

- 通过 `BusinessDesktopRoutesWithoutMainLayout` 注册；Web/Electron 同步。
- 匿名用户跳登录；已登录无权限显示 403；不加载敏感数据。
- 菜单权限只影响可见性，Procedure 权限才是安全边界。
- 移动端首版显示明确不支持页面，不渲染桌面表格缩小版。
- 页面均需覆盖 loading、empty、error、forbidden、revision conflict、read-only、pending restart。

## W2 实施状态

- `/admin`、`/admin/users`、`/admin/users/:id` 已在 M03/M04 落地；desktop/web route tree 同步，企业 Flag 关闭时 registry 返回空数组。
- 移动端 `/admin` 已落地明确不支持面，不加载桌面管理表格。
- 用户详情已包含 Overview、Access、Sessions、Audit、Danger Zone；Audit 无权限时不发请求。
- 其余 URL 保留为后续模块交付，不得用占位管理写接口提前驱动运行时。

## W3 实施状态

- `/admin/settings` 已在 M05 落地 Draft/Validate/Publish/Rollback、CAS 冲突处理、重新认证和默认 / 锁定 / 隐藏策略编辑。
- `/admin/managed-resources` 已在 M06 落地 Provider/Model/Skill/Connector/Agent 五类策略、observe/ui-only/enforced、readiness 与影响预览。
- 普通用户侧 Provider、Model、Skill、Connector、Agent 配置入口按公开能力快照收口；Feature Flag 关闭时不请求托管能力且保持上游 UI。
- 其余管理 URL 从 M08 继续交付，不得提前启用托管运行时。

## W4 实施状态

- `/admin/ai/providers`、`/admin/ai/providers/:id`、`/admin/ai/models` 已为真实页面；auditor 可进入 Provider 详情但仅只读。
- Test、Secret、Publish、Archive 与 Model 操作分别按独立权限显示和调用；model-only 管理不依赖 Provider update。
- 零 Model Provider 通过服务端搜索 / 游标选择器可发现，不需手输 UUID；异步刷新未完成时锁定旧 CAS 写操作。
- 普通用户模型选择器仅消费同一个 Secret-free Published runtime state。
