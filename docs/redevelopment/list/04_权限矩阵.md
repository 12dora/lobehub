| ---------------- | --------------------------------------------------------- | ------------- | ------------ | ---------- | ---------- | ------------ | -------- | ----------------- | ------------ |
| super\_admin     | 全部平台权限                                              | 是            | 是           | 是         | 是         | 是           | 是       | 是                | 是           |
| user\_admin      | 用户读写、Session、角色包（不可管理 super\_admin）        | 是            | 是           | 否         | 否         | 否           | 否       | 否                | 受限         |

| auditor          | 所有管理资源只读、审计导出                                | 只读          | 否           | 只读       | 只读       | 只读         | 只读     | 只读              | 只读         |

## 权限代码建议

```text
platform_admin:access:all
platform_user:read|update|ban|session_revoke|role_manage:all
platform_settings:read|update|publish:all
platform_policy:read|update|publish:all
platform_ai_provider:read|create|update|delete|test|publish:all
platform_ai_model:read|create|update|delete|publish:all
platform_skill:read|create|update|delete|publish:all
platform_connector:read|create|update|delete|test|publish:all
platform_agent:read|create|update|delete|publish|assign:all
platform_identity:read|create|update|delete|test|publish:all
platform_branding:read|update|publish:all
platform_audit:read|export:all
platform_system:read|operate:all
```

平台权限必须显式匹配 `workspace_id IS NULL`。任何 workspace role 均不能满足上述权限。

## M07 落地约束

- Provider `list/get/listRevisions` 仅要求 `platform_ai_provider:read`；auditor 可读详情，但看不到可用写入入口或 Secret。
- Provider mutation 分别校验 create/update/delete/test/publish，不用粗粒度 update 代替。
- Model create/update/delete/reorder 仅要求对应 Model 权限，不附加 Provider update；创建目标列表仅需 Model create 且严格最小输出。
