# 验收与回归矩阵

| 领域          | 最低验收标准                                                          | 责任模块    |
| ------------- | --------------------------------------------------------------------- | ----------- |
| 权限          | 普通用户和 workspace owner 访问 /admin/API 均拒绝；最后超级管理员保护 | M02/M03/M15 |
| 用户          | 搜索 / 筛选 / 封禁 / 解封 / Session / 角色均审计                      | M04         |
| 设置          | 未覆盖继承新默认；显式覆盖保持；locked API 拒绝；单路径恢复           | M05         |
| Managed Guard | 直接调用旧 Mutation 失败；用户仍能使用发布资源                        | M06         |
| AI            | Draft/Test/Publish/Rollback；Secret 不回显；Runtime 一致              | M07         |
| Skill         | 版本不可变；校验 / 依赖 / 回滚；用户不可编辑                          | M08         |
| Connector     | SSRF/OAuth 隔离 / Tool deny；每用户绑定                               | M09/M13     |
| Agent         | 全用户 Assignment、Rollout、Inbox 兼容、依赖校验                      | M10         |
| OIDC          | Authentik 测试、Pending Restart、LKG、Break-glass                     | M11         |
| Branding      | 登录 / 导航 / Title/Manifest/ 邮件 / Inbox 一致；内部标识不改         | M12         |
| 运维          | Revision 收敛、Redis/KMS/Job/ 实例状态可观测                          | M14         |
| 升级          | 2.2.10 数据升级、应用回滚、上游 Rebase E2E                            | M15         |

## 发布签字

- 产品：业务规则、UI 文案、用户影响。
- 架构：数据所有权、运行时解析、上游兼容。
- 安全：RBAC、Secret、SSRF、OIDC、审计。
- DBA：迁移、索引、锁、备份和回滚。
- 运维：Feature Flag、监控、告警、Runbook、滚动重启。
- QA：权限矩阵、E2E、回归、性能和灾备演练。

## W2 验收证据

- M03：普通用户 /workspace owner 不挂载管理业务数据；无权限显示 403，未知路径 404；Flag 关闭时 admin registry 为空；desktop route 双配置同步。
- M04：搜索 / 状态 / 角色 / 日期 /cursor/page-size 真实请求证据；封禁 / 解封 / Session / 角色写入均要求 reason，高风险动作 reauth，成功 / 失败 / 拒绝均审计。
- M04 安全：最后超管保护、workspace role 不受影响、现有 Session 安全 epoch、当前 Session 保留例外实时验证、OIDC 强制重新登录、popup state/origin/source/replay、unmount/destroy abort 均有对抗测试。
- 合并后 19 个聚焦测试文件 192 项通过，完整 type-check 与企业路径边界通过；Migration 0119 journal/snapshot 为 120/120。

## W3 验收证据

- M05：未覆盖继承新默认、显式覆盖保持、locked/hidden API 拒绝、单路径恢复与旧设置兼容写均有后端 / UI 回归；发布 / 回滚使用 revision + draft token CAS、reason、reauth 和审计。
