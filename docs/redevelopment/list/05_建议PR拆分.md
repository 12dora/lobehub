# 建议 PR 拆分与合并顺序

| PR 范围 | 模块 | 内容 | 合并/启用原则 |
| --- | --- | --- | --- |
| PR-001–004 | M00 | 企业目录、类型、Feature Flag、挂载点 | 关闭 Flag 行为不变 |
| PR-005–008 | M01 | 平台表、Revision、Audit、Job | Migration 0；无业务切换 |
| PR-009–013 | M02 | 权限、Global Query、Middleware、Bootstrap | 真实 RBAC 先测试后启用 |
| PR-014–017 | M03 | Admin Shell、路由、通用 UI | 先只读空壳 |
| PR-018–021 | M04 | 用户、封禁、Session、角色 | 先只读后危险写 |
| PR-022–026 | M05 | Registry、Resolver、Override、UI | 先 Shadow 再生效 |
| PR-027–030 | M06 | Managed Policy/Guard/UI 收口 | observe-only→enforced |
| PR-031–036 | M07 | Provider/Model/Secret/Runtime/UI | 先测试 Provider |
| PR-037–040 | M08 | Skill Version/Validator/Runtime/UI | 先只读目录 |
| PR-041–046 | M09 | Connector/SSRF/OAuth/Tool/UI | 按凭据风险逐步启用 |
| PR-047–052 | M10 | Agent/Assignment/Inbox/Rollout | Optional→Mandatory→Inbox |
| PR-053–057 | M11 | OIDC/测试/LKG/重启/AuthentiK | 独立发布窗口 |
| PR-058–062 | M12 | Branding/Provider/i18n/扫描 | 名称→资产→桌面构建 |
| PR-S01–S05 | M13 | 安全横切 | 在相关模块前合入 |
| PR-O01–O05 | M14 | 一致性/观测/系统页 | 关键告警先于全量 |
| PR-Q01–Q06 | M15 | 测试/迁移/Rebase/Runbook | 贯穿所有 PR |

## PR 大小要求

- Schema/Migration 与业务切换分开，便于数据库审查和回滚。
- Runtime Adapter 与 UI 分开，避免页面完成但执行链不可用。
- 每个 PR 明确：Feature Flag、权限、Audit、Migration、Secret、缓存、测试、回滚。
- 单个 PR 不同时首次启用 OIDC、Connector 共享账号、默认 Inbox 或 Branding 切换。
