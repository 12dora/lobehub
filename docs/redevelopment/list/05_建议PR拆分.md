## PR 大小要求

- Schema/Migration 与业务切换分开，便于数据库审查和回滚。
- Runtime Adapter 与 UI 分开，避免页面完成但执行链不可用。
- 每个 PR 明确：Feature Flag、权限、Audit、Migration、Secret、缓存、测试、回滚。
- 单个 PR 不同时首次启用 OIDC、Connector 共享账号、默认 Inbox 或 Branding 切换。
