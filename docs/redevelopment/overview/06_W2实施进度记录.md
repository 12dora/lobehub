## 2. M03 可复用能力

- `createAdminRouteTree` 与 desktop/web 双配置同步；企业 Flag 关闭时不注册任何 admin 路由，移动端只呈现明确的不支持页面。
- `AdminAccessProvider`/root gate 在子页面请求前完成登录、Feature Flag 与 `platform_admin:access` 判定；菜单隐藏不作为安全边界。
- `AdminLayout`、`AdminSideNav`、`AdminPageTemplate` 和 primitives 桶可直接供 M05–M12 管理页使用。
- `DataTable` 使用真实 cursor pagination，不伪造 total；`FilterBar`、`StatusBadge`、`RevisionBanner`、`DangerConfirm` 已覆盖 loading/empty/error/forbidden 等壳层状态。
- 上游兼容点保持薄：Business desktop/mobile route mount、GlobalServerConfig 的 `platformAdmin` 能力位和 Settings `SectionGroup` adapter。

## 3. M04 服务端与安全交付

- 严格 Zod input/output contract：`list/get/ban/unban/revokeSessions/replaceGlobalRoles/getAuditTrail`；输出只含安全投影，不返回密码、Token、Provider Key 或消息内容。
- `AdminUserModel` 使用规范化前缀检索、keyset cursor、批量 Provider 摘要；Migration 0119 只增加 `users.auth_invalidated_at`、`users.auth_invalidated_excluded_session_id` 和 3 个 `lower(...) text_pattern_ops` 索引。
- 封禁在 Better Auth 管理 mutation、认证 route、tRPC context / 关键业务 procedure 多层 fail-closed；会话撤销使用安全 epoch，并实时验证保留的当前 Session，避免复用伪造 / 过期 exception。
- 角色替换只操作 global roles，不碰 workspace roles；永久 `super_admin`、最后超管保护和事务 / 并发对抗测试已闭环。
- 危险写入要求 reason、近期重新认证和审计；失败 / 拒绝也持久化审计。OIDC reauth 使用 `prompt=login`、`max_age=0`，popup 校验 crypto state、origin、source 并防 replay。
- 重新认证重试使用不可变 canonical payload；关闭、Escape、RTL unmount、Modal destroy 都同步 abort，迟到成功不得触发第二次 mutation。

## 4. M04 管理端交付

- `/admin/users` 支持搜索、状态、角色、完整注册日期范围、page-size 和 cursor 翻页；过滤条件与 cursor 原子更新。
- `/admin/users/:id` 提供 Overview、Access、Sessions、Audit 和独立 Danger Zone；服务端计算 `isSelf`，自封禁隐藏，自撤销会话有保留当前 Session 的显式策略。
- 角色弹窗按 actor eligibility 限制；`user_admin` 不能授予 `super_admin`，`super_admin` 不允许到期时间，异常共存状态 fail-closed。
- 搜索从第二页修改时，debounce 前零请求，提交后只有一个新 query/no-cursor 请求。回归测试在父提交 `773a633` 能稳定捕获旧实现的两次请求。
