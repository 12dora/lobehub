## 并行原则

- M00 与 M01 可以由平台架构和数据库负责人并行，但 Schema 命名、Feature Flag 和错误码必须先对齐。
- M03 的静态布局可以与 M02 并行；任何真实管理数据查询必须等 M02 的只读权限中间件可用。
- M08 与 M09 可并行；M09 必须接受独立 SSRF、OAuth、凭据存储安全评审。
- M11 与 M12 可并行，但不得在同一生产发布窗口首次启用。
- M13–M15 是横切模块，从 W1 起持续执行，而不是最后补文档。
