## 本地命令（已测）

```bash
# 契约 / harness 校验（不得写出 production overall=passed）

  --candidate .records/enterprise-production-readiness/candidate.json \
  --plan .records/enterprise-production-readiness/plan.json \
  --evidence-dir .records/enterprise-production-readiness/evidence \
  --output .records/enterprise-production-readiness/report.json

# 生成默认 Milestone A–F 发布计划
bun run enterprise:preflight emit-default-plan \

  --release-id "rc-local-demo" \
  --output .records/enterprise-production-readiness/plan.json

# 只读解析 allowlisted 命令（默认 dry-run）
bun run enterprise:preflight dispatch --command-id preflight-validate

# 本地 harness 备份恢复（owned 临时 PostgreSQL；scope=local-harness）
bun run enterprise:recovery-drill backup-restore \
  --candidate-sha "$(git rev-parse HEAD)" \
  --schema-tag "0136_m11_identity_secret_state_null_guard" \
  --scope local-harness \
  --output .records/enterprise-production-readiness/evidence/backup-restore.json

# 生产路径参数（需外部签名 dump+manifest；仓库无生产公钥时仍无法 overall=passed）
bun run enterprise:recovery-drill backup-restore \
  --candidate-sha "$(git rev-parse HEAD)" \
  --schema-tag "0136_m11_identity_secret_state_null_guard" \
  --scope production-authorized \
  --backup-file /path/to/signed.dump \
  --source-manifest /path/to/source-manifest.json \
  --provenance /path/to/provenance.json \
  --release-id "rc-prod" \
  --output .records/enterprise-production-readiness/evidence/backup-restore.json

# 应用版本回滚兼容（无完整 baseline ORM 运行时 → unverified，永不 planted-probe pass）

  --candidate-sha "$(git rev-parse HEAD)" \
  --scope local-harness \
  --output .records/enterprise-production-readiness/evidence/app-rollback.json
```

E2E 已测路径：`enterprise:recovery-drill backup-restore` 写入证据目录后，再对**同一目录**运行 `enterprise:preflight validate-harness`（含 `raw/` 邻居文件）；preflight 只消费 envelopes，不得把 raw 当 gate。

## 证据目录布局（硬契约）

```text
<evidence-dir>/
  envelopes/
    backup-restore.envelope.json   # 仅此处（及同名 gate）被 preflight 扫描
    app-rollback.envelope.json
    …
  raw/
    backup-restore.raw.json        # 完整 drill 报告；preflight 不扫描
    app-rollback.raw.json
  backup-restore.json              # 便捷 envelope 副本（可选）
```

- Preflight **只**加载 `envelopes/<gate>.envelope.json`（fallback：根目录精确 gate 名 `*.envelope.json`）。
- `raw/**`、未知 JSON、额外文件 **故意忽略**，不得静默当 gate 证据。
- Envelope 的 `artifactSha256` 绑定 **raw 报告** 字节（非 dump）。
- Envelope **嵌入** sanitized `rawReport`；loader 重算 digest 必须等于 `artifactSha256`。
- 生产 `backup-restore` preflight：从 raw 提取 `inputAttestation.inputAttestationSha256`，作为 `expectedInputAttestationSha256` 校验 recovery-result 签名（独立于 finalize 时刻）。

## 签名 provenance（两层，不可混用）

| 角色              | 何时           | `artifactSha256` | 用途                                    |
| ----------------- | -------------- | ---------------- | --------------------------------------- |
| `source-backup`   | 恢复前         | dump digest      | dump+manifest 输入证明；仅 restore 校验 |
| `recovery-result` | raw 报告写出后 | raw 报告 digest  | 仅 gate envelope /production preflight  |

- 运行时 **无生产私钥**：restore 写出 **unsigned** envelope + raw 内 `inputAttestation` 摘要引用。生产 pass 需外部对 raw 签名后 `finalize-result` 导入 `recovery-result`。
- **禁止**把 source-backup 挂到 preflight envelope（会 `artifact-digest-mismatch` / `attestation-role-mismatch`）。
- CLI 两步：

```bash
bun run enterprise:recovery-drill backup-restore \
  --scope production-authorized --backup-file dump --source-manifest manifest.json \
  --provenance source-backup.sig.json --candidate-sha SHA --schema-tag TAG --release-id rc \
  --output evidence/backup-restore.json

bun run enterprise:recovery-drill finalize-result \
  --raw-report evidence/raw/backup-restore.raw.json \
  --envelope evidence/envelopes/backup-restore.envelope.json \
  --result-provenance recovery-result.sig.json --candidate-sha SHA --release-id rc
```

- CLI **永不**接受 trust-policy 路径 / 环境变量覆盖；测试密钥仅 test API。

## Baseline 执行边界（诚实）

- 钉死 commit：`4bab1636408e60a7ee17b640490fbf33a310a325`（LobeHub 2.2.10）。
- Materialize 仅 `git show` 钉死 blob；**禁止**种植当前分支 probe。
- 无完整 baseline ORM → `baselineExecutable=false`、`unverified`。

## 表摘要与 publication 指针

- 表 digest 使用 **versioned 规范 JSON 投影**（列序 / 类型 /null/secret 分类哈希）；禁止未转义 `|`/ 换行拼接。
- Publication：`resource_type` + owner id + revision/version id + 目标 checksum；agent/skill 走版本表 owner FK。

## 命令状态（跨进程）

- `readiness-command-state.json`：O\_EXCL 锁、原子 rename、重读后置条件、operation-id 有界 replay ledger。
- 同 operation 重放返回已记录非重复执行结果；冲突 / 锁超时非零；并发独立更新串行化后两者均存活（或一方显式 timeout/conflict）。

## Q03 / Q05 / O05 适配器

- 适配器解析 **生产者真实严格 schema**（`verify-migration` / `upstream-rebase-ci` / `failure-drills`），不发明字段。
- 生产者可选输出 `generatedAt` 与 full `candidateSha`/`gitSha`；缺失时间戳 → adapter **unverified**（不得伪造新鲜度）。

## 结果语义

| overall / status              | 含义                                                                                                                   |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `passed`                      | 仅当 `production-authorized` 模式 + 仓库钉死 Ed25519 trust policy 校验通过，且七门禁均为 production 环境签名证据时可达 |
| `failed`                      | 签名 / 重放 / 摘要失败、门禁失败、新鲜度失败、候选不一致、清理失败等                                                   |
| `unverified` / `not-executed` | 缺证据、仅 harness、baseline ORM 不可执行、生产公钥未配置；**不得**记作生产通过                                        |

硬约束：

- 自声明 `scope: production-authorized`、`--production-ack`、任意 trust-policy 路径 / 环境变量 **不能** 升级生产通过。
- 仓库内 `PRODUCTION_TRUST_POLICY` 当前 **无生产公钥** 且 `productionPassEnabled=false`，CLI 生产 overall pass 在 reviewed 公钥合入前 **不可能**。
- 证据年龄只看 `generatedAt`；`observedAt` 不能把过期证据刷成 fresh。
- `validate-harness` / CI 即使契约全绿，也 **不得** 发出 production `overall=passed`。
