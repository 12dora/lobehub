# W10 实施进度记录(管理面板与用户端一致化)

日期:2026-07-21。触发:体验实例交付后,产品负责人提出管理面板三项修复需求。工作流:grok(reasoning-effort high)实施 + 独立 Claude 审核,REWORK 经 `--resume` 同会话返工、同审核员复验,PASS 后 `--no-ff` 合入 main。

## 需求

1. 「AI 基础设施-服务商」页与用户端「设置-智能体-AI 服务商」完全一致(仅数据为全局配置);
2. 「AI 基础设施」整组菜单与用户端「设置-智能体」的服务模型/技能/Connectors/记忆设置/凭证管理一致(全局配置);
3. 管理平台新增全局所有用户的数据统计,逻辑与 UI 同用户端「设置-数据统计」。

## 架构决策(实施前定稿)

- **否决 header 切作用域**:仓库内 workspace/RBAC 中间件为 fail-open stub,透传 header 无兜底;
- **全局读取一律走 M04 先例**:专用无 ownership model(`constructor(db)`)+ `withPlatformPermission` 守护;
- **UI 复用一律走注入缝**:StatsDataSource context(统计)、aiInfra store 工厂+context(服务商)、受控 View 抽取(服务模型/记忆/STT/图像)、CredsApiProvider platform 模式(凭据)、props 化(PlatformSkillItem);用户端默认路径零行为变化是每波审核的硬验收项;
- **管理端保存即生效**:各域新增 `applyImmediate`(改草稿+发布合一,guard 全套:权限二次校验/无条件 reauth/限流/审计;create 软失败 `published:false` + banner + `publishNow` 重试);
- **M13 红线贯穿**:平台 Secret 只 merge 不整仓覆盖、任何 API 不回显明文、掩码字面量写入被服务端拒绝。
