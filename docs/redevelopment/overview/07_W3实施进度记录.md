## 2. M05 交付

- 管理端 `/admin/settings` 支持本地 Draft、严格校验、CAS 保存/发布/回滚、三方冲突合并、近期重新认证、reason 与审计；发布和回滚同时绑定 revision 与 draft token。
- Resolver 区分平台默认、用户显式覆盖、锁定与隐藏；未覆盖路径继承新默认，显式覆盖保持，locked/hidden 服务端 fail-closed。
- 旧 `updateSettings` 与 `getUserState` 通过适配器读取有效设置，Feature Flag 关闭时保持上游行为；`keyVaults` 不进入平台 Override。
- Migration `0120` 增加 visibility、bundle pointer 与 override revision；生成 SQL 只含 M05 对象。

## 3. M06 交付与安全闭环

- `/admin/managed-resources` 管理 Provider、Model、Skill、Connector、Agent 五类策略；Draft/Published 分离，发布需 CAS、近期重新认证、reason、审计和 readiness。
- Guard 覆盖 10 个 Router、99 个 Mutation；observe/ui-only 只记录脱敏 would-deny，enforced 返回稳定错误 `RESOURCE_MANAGED_BY_PLATFORM`，超级管理员通过普通用户 API 也不能绕过。
- AgentDocument 使用与 VFS 相同的 canonical path normalizer，Skill 路径及模糊/非法 source/target 均 fail-closed；普通文档读写保持可用。
- 托管 Connector 保留 Tool 权限与个人 OAuth 生命周期，禁止定义同步、编辑、删除和凭据写入；Composio create/update/get/delete 使用当前用户本地 projection，并以远端 owner-filtered 分页查询再次证明绑定归属。
- 客户端不再提交 Tool 定义快照或任意远端 account id；服务端从可信 catalog/Composio 重新读取工具。遗留“本人本地行指向他人远端绑定”在四条路径全部拒绝，删除路径无远端副作用。
- Flag 关闭精确恢复上游行为；发布回滚到 `managed=false` 可解除托管。M06 复用既有 `platform_managed_resource_policies`，无新增迁移。
