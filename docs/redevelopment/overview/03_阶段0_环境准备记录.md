## 1. Authentik(auth.jiefakj.com,本机 :19000)

- 已创建 OAuth2/OIDC Provider **AIHub OIDC**(pk=4):
  - `client_id = aihub`,confidential,grant_types = authorization_code + refresh_token,PKCE 兼容
  - scope mappings:`openid`、`email`、`profile`、`dingtalk`(钉钉 claim:dingtalk_user_id/union_id/corp_id/department_ids)
  - 签名密钥与 easytrade Provider 一致(JWKS 已验证有 key),sub_mode = user_uuid
  - redirect URIs(strict):
    - `http://localhost:3210/api/auth/oauth2/callback/authentik`(现运行实例)
    - `http://localhost:3010/api/auth/oauth2/callback/authentik`(dev)
    - `https://aihub.jiefakj.com/api/auth/oauth2/callback/authentik`(预留公网域名,frps 侧尚未配置)
- 已创建 Application **AIHub**(slug=aihub)
- **email 兜底映射**:钉钉通讯录用户普遍无邮箱,而 Better Auth 建账号必须有 email。aihub Provider 的 `email` scope 使用专用映射「AIHub email with DingTalk fallback」:有真实邮箱返回真实值;为空则合成 `<钉钉user_id>@dingtalk.jiefakj.com`(该域不收信,仅作稳定标识),`email_verified=true`。仅绑定在 aihub Provider,不影响 EasyAuth/EasyTrade。
- Issuer:`https://auth.jiefakj.com/application/o/aihub/`(公网 discovery 已验证 200)
- 幂等配置脚本:按 EasyAuth `docs/guides/authentik-easyauth-automation-setup-llm.md` 约定编写(只增不删)
